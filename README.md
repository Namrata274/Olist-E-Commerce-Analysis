# Olist-E-Commerce-Analysis

# 1. Project Overview
​An end-to-end business intelligence solution built using Power BI to analyze the Brazilian e-commerce dataset (Olist). This dashboard delivers deep insights into customer behavior, order statuses, regional sales distributions, delivery performance, and overall revenue trends.

# 2. Dashboard Preview & Pages
​**Executive Summary & KPIs** – Highlights core business metrics like Total Revenue, Total Orders, Total Customers, Total Products, and Customer Review distributions.    
​**Regional & Operational Insights** – Features geographical distribution by states/cities, order status tracking across weekdays, and comparative metrics like average price vs. payment values.

# 3. Key Features & Technical Implementation
​**Data Cleaning & Transformation:** Utilized Power Query for cleaning raw relational tables, handling missing values, and formatting timestamps.  
​**Data Modeling:** Established a robust relational schema connecting orders, customers, items, payments, and reviews.  
​**DAX Measures & KPIs:** Created dynamic calculated measures for tracking business performance indicators (e.g., Total Revenue, Average Delivery Days, Review Scores).  
​**Interactive Filtering:** Implemented cross-filtering and slicers (Day Type, Day Name) for seamless data slicing and user interactivity.

# 4. Key Insights Uncovered
​**Revenue & Orders:** Handled over 96K+ orders generating a massive revenue scale, with weekdays seeing a significantly higher order volume compared to weekends.  
​**Customer Satisfaction:** A dominant share of customers provided 5-star ratings, indicating overall high satisfaction despite logistical variables.  
​**Geographical Trends:** States like SP (São Paulo), RJ (Rio de Janeiro), and MG (Minas Gerais) drive the maximum customer base and order counts.  
​**Delivery Performance:** Monitored average delivery durations across categories like Pet Shop and general fulfillment cycles.  

# 5. Tech Stack
​**BI Tool:** Power BI Desktop  
​**Data Prep:** Power Query, DAX (Data Analysis Expressions)  
​**Dataset:** Olist Brazilian E-Commerce Public Dataset
